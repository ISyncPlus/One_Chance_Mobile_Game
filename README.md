# One Chance Mobile

Production mobile foundation for an offline-first, landscape, pass-and-play board game. **Phase 2: a pure deterministic domain foundation exists; no consumer gameplay is implemented.**

## Development

Use Node 24.20.0 and npm 11.19.0 (see `.nvmrc` and `package.json`).

```sh
npm ci
npm run check
npm run check:dependencies
npm run doctor
npm run ios
# Or, with the Android SDK configured and a device/emulator available:
npm run android
```

`npm start` starts Metro for the development client. Native dependency/config changes require rebuilding the client. Use Expo development builds, not Expo Go, for acceptance. First native builds need the platform toolchains and dependency downloads; the shipped application must not.

Native directories are generated by Expo Continuous Native Generation and are ignored. Make native changes through `app.config.ts` and config plugins. Do not hand-edit generated projects as the source of truth.

## Diagnostic

Development builds open **RENDERING LAB**, a temporary coordinate grid and token. It is not a game board or an art direction proposal. Pan, pinch, tap the token, move it, fit the camera, invoke haptics, and capture UI frame intervals. SQLite connection policy is displayed. The diagnostic is reachable only through the `__DEV__`-guarded bootstrap entry.

Release builds show a neutral foundation screen. No match creation or gameplay is advertised. See [device verification](docs/architecture/device-verification.md) for inspection and performance limitations.

`npm run check` runs strict app and pure-game type checks, ESLint, an AST-based import audit, and Node's built-in test runner. Tests run without React Native or a simulator. Native diagnostic acceptance uses the isolated [host tooling](scripts/acceptance/README.md); match persistence integration tests remain outside the current implementation.

The app's local bundle/package ID is `com.onechance.mobile`. Confirm the publisher-owned namespace before signing or store distribution. This is not a claim of namespace ownership.
